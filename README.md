# Data Science, Big Data & Business Analytics – Master's Portfolio

Welcome to my Data Science, Big Data & Business Analytics portfolio! This repository contains the coursework, projects, and assignments completed during my Master's program at the Complutense University of Madrid. The program provided a strong foundation in data science, machine learning, and big data technologies, combining both theoretical knowledge and hands-on experience.

This repository is organized into different modules covered in the master's program:
